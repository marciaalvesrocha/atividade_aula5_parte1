# 🎮 Atividade: HTML Básico - GameZone Retro

Este repositório contém o código de uma página web simples criada para a loja fictícia **GameZone Retro**, desenvolvida como parte de uma atividade prática de HTML.

## 🎯 Objetivo da Atividade
O desafio consistia em construir uma página HTML funcional cobrindo elementos essenciais de estruturação e formatação, respeitando o limite máximo de **50 linhas de código**.

---

## 🛠️ Conceitos e Tags Utilizados

Durante a atividade, foram aplicados os seguintes conceitos do HTML5:

- **Estruturação de Texto:** Uso de cabeçalhos (`<h1>`, `<h2>`), parágrafos (`<p>`) e formatação de texto (`<strong>` para negrito e `<em>` para itálico).
- **Mídia e Links:**
  - Adição de links externos (`<a>` apontando para redes sociais com `target="_blank"`).
  - Link de ancoragem interna (`href="#tabela"`).
  - Inserção de imagens (`<img>`) com dimensões especificadas (`width` e `height`).
- **Listas:** Construção de listas não ordenadas (`<ul>` e `<li>`) para exibição dos consoles disponíveis.
- **Tabelas:** Estruturação de dados com tabelas (`<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`) para exibição de produtos e preços.
